Weekly Sweep Model — chart key

Every mark the indicator draws, and what it is telling you. Teal = bullish · red = bearish · grey = neutral.
1 Weekly — the bias must happen first
PWH
Previous week’s high. The liquidity sitting above the market.
PWL
Previous week’s low. The liquidity sitting below the market.
sweep PWH
High taken → short bias
Marks the candle that raided last week’s high. Now look for shorts only.
sweep PWL
Low taken → long bias
Marks the candle that raided last week’s low. Now look for longs only.
2 HTF key level — the location price must be inside one
HTF FVG
Bullish 4H fair value gap
A 3-candle imbalance. Valid place to look for a long. Dies if a 4H candle closes below it.
HTF FVG
Bearish 4H fair value gap
Valid place to look for a short. Dies if a 4H candle closes above it.
4H support zone
Dotted border, no text. A confirmed 4H swing low, padded by ATR into a band.
4H resistance zone
A confirmed 4H swing high, padded into a band.
Hidden zone
Faded out because price is far away — but still live. It counts again if price returns.
3 15m structure — the confirmation must agree with the bias
Bullish break 15m ^
A 15m candle closed above the last confirmed swing high. Dashed line marks the broken level.
Bearish break 15m v
A 15m candle closed below the last confirmed swing low.
MSS  BOS
v1 tags only
MSS = structure flipped direction. BOS = broke the way it was already going. v2 shows 15m ^ / v instead.
4 Execution — the trigger on your 1–5m chart
iFVG
Inverted fair value gap
A gap price traded through, now flipped polarity. A bearish gap closed above becomes support.
CISD level, bullish
Open of the first candle of the down-run. Thin line, appears and vanishes. Close above it = trigger.
CISD level, bearish
Open of the first candle of the up-run. Close below it = trigger.

The order is the method. A mark on its own means nothing — they only count in sequence:
weekly sweep→HTF key level→15m structure→iFVG / CISD→entry
An opposite 15m break at any point cancels the setup. Each stage expires if the next one takes too long. Trade levels are drawn for study only — the indicator places no orders.
