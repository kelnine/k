# Dashboard (Phase 8)

React + TypeScript + Vite single-page app with a dark trading-terminal theme,
served as static files by Caddy and talking to the `api` process over
REST + WebSocket. See [docs/02-tech-stack.md](../docs/02-tech-stack.md#22-frontend-phase-8)
for the stack and [docs/01-architecture.md](../docs/01-architecture.md) for the pages:

Overview · Strategies · Strategy Comparison · Accounts · Open Positions ·
Trade History · Analytics · Prop Rules · TradingView Signals · Telegram ·
System Logs · Settings

Nothing is built here until Phase 8; the backend API it needs is built first.
